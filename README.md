# culdechat.app

The public website for CulDeChat: home page, Support, Privacy Policy, Terms of Service, Community Guidelines, and Delete your account. Published with GitHub Pages at https://culdechat.app.

These files are generated in the (private) app repository: the legal pages come from `docs/legal/`, and Support / Delete your account from `site_src/`, built with `python tools/build_site.py` into `site/`. To update the website, rebuild there and copy `site/` here.
